Phone App & Downloadable APK Guide

Your notes, workout logs, and meal progress are saved inside on-device LocalStorage (and you can export a JSON Backup anytime in the EPI Java tab).

1. Instant Zero-Build Android App (PWA)

Open this file in Chrome on Android → Tap ⋮ (Three Dots) → "Add to Home screen" / "Install app". Android compiles a native WebAPK wrapper automatically with full offline storage.

2. Build a Standalone .APK File

Save this code as index.html and wrap it using Capacitor (npx cap add android), Cordova, or PWABuilder. In Android WebView, ensure domStorageEnabled = true is enabled so all custom notes persist across app restarts.
